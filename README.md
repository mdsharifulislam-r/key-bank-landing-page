# KeyBank landing page

Marketing site for KeyBank, a contactless key-handover app for short-term rental hosts. Built with Next.js App Router, TypeScript, and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The root path redirects to a locale. English is `/en`, Arabic is `/ar` (right to left), and French is `/fr`.

```bash
npm run lint
npm run build
```

## Edit copy

Marketing copy lives in `data/`. English, Arabic, and French each have a full object. Edit the locale you want to change. If a locale object is missing, that section falls back to English.

| What | File |
| --- | --- |
| Navigation and language labels | `data/navigation.ts` |
| Hero | `data/hero.ts` |
| Trust stats (placeholders) | `data/stats.ts` |
| Problem and solution | `data/problem.ts` |
| How it works | `data/how-it-works.ts` |
| Feature cards | `data/features.ts` |
| Host and guest showcase | `data/showcase.ts` |
| Live alerts | `data/notifications.ts` |
| Duration package prices | `data/pricing.ts` |
| Hardware and payments | `data/integrations.ts` |
| Download band | `data/download.ts` |
| Sample reviews | `data/testimonials.ts` |
| FAQ | `data/faq.ts` |
| Newsletter form | `data/newsletter.ts` |
| Footer | `data/footer.ts` |
| Titles and descriptions | `data/seo.ts` |

`data/pricing.ts` feeds both the pricing cards and the `SoftwareApplication` offers in the JSON-LD. Replace the sample quotes in `data/testimonials.ts` before launch. Do not add review structured data until those quotes are real.

The newsletter form validates email on the page only. Connect it by posting to an API route where `components/sections/Newsletter.tsx` is marked with `TODO`.

## Replace images

Swap files in `public/images/` and keep the filenames:

- `logo.svg`, `favicon.png`, `og-image.png`
- `hero-phone.png`
- `app-host-1.png` (home), `app-host-2.png` (My Locker), `app-host-3.png` (profile)
- `app-guest-1.png` (welcome), `app-guest-2.png` (home)
- `app-pricing.png` (duration packages)
- `notification-1.png` through `notification-4.png` (icons on the alert cards)
- `avatars/1.jpg` through `avatars/5.jpg`
- `badge-appstore.svg`, `badge-googleplay.svg`

`components/ui/PhoneMockup.tsx` shows the screenshot as-is, with a shadow. The app captures already include the phone, so do not add a second bezel. The pricing section uses `app-pricing.png` beside the plan cards.

The live social preview is generated by `app/opengraph-image.tsx`. `public/images/og-image.png` is a static copy of that layout you can replace if you point metadata at the file instead.

Regenerate the built-in placeholders with:

```bash
npm run placeholders
```

## Change the primary color

Edit the `primary` scale in `tailwind.config.ts`. `primary.500` is the brand gold, `#C9961B`. Keep the rest of the scale in step with it so hovers, borders, and the hero curve stay related. `cream`, `brown`, `navy`, and `mist` are the supporting tokens in the same file.

## Deploy on Vercel

1. Push the repository to GitHub.
2. Import the project in [Vercel](https://vercel.com/new).
3. Set `NEXT_PUBLIC_SITE_URL` to the production origin, without a trailing slash. Example: `https://keybank.app`. This value is used for canonical URLs, hreflang, the sitemap, and JSON-LD.
4. Deploy. Vercel detects Next.js. No extra build command is required.

`/` redirects to `/en`, `/ar`, or `/fr` from the visitor’s `Accept-Language` header, and otherwise to English. Arabic pages set `dir="rtl"`.
